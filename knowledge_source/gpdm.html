11Publishing Fix from DB ▾

If a publishing job is stuck in Executing state:

Go to the publisher processing the job (CAD/Office) and verify there are no prompts or system errors.

If none, verify that the document has passed the timeout value.

If timeout has passed and the job is still executing, go to the database and run:

3a) PROD

💻 Command / Script
sqlplus fmc_prod/fmc_prod@windchill-prod-rds.cuspr3i0bitd.eu-central-1.rds.amazonaws.com:1521/ORACLEDB

3a) QA

💻 Command / Script
sqlplus fmc_qa/FMC_QA@windchill-qa-rds.cvk518vytl8k.eu-central-1.rds.amazonaws.com:1521/ORACLEDB

3b)

💻 Command / Script
select entryNumber, codec5, ida2a2 from queueentry where codec5='EXECUTING' AND targetClass='com.ptc.wvs.server.publish.PublishJob' AND entryNumber=<Job id from WVS Job Monitor>;

3c)

💻 Command / Script
UPDATE QUEUEENTRY set codec5='NONEVENTFAILED' where ida2a2='<ida2a2 from above>' and codec5='EXECUTING';

3d)

💻 Command / Script
commit;

If publishing jobs are not moving forward after the SQL change, restart the BackgroundWVS process.

19Standard QDOK Rename Rejection Response ▾

Dear (add person name),

📣The Support Team cannot rename the document. The Global Document Control department has communicated that any document that is already in approved or effective state needs to go through the change control process / document control (at local level) for performing a title update. The rationale is that a title change impacts all previous revisions of a document, and it is important to maintain the traceability of such a change. This is not possible with an administrative change.

📧If you have any additional questions relating to the renaming process defined by the business, please contact CDO@freseniusmedicalcare.com.
